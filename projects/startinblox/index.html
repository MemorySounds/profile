Startin'Blox

Company Website
OVERVIEW

Startin'Blox builds dataspaces: networks where organisations share data with each other without handing it over to a central platform. I worked with them part-time on EU-funded research projects, mainly for the European Media Data Space (TEMS), where media organisations can search what others offer, such as 3D models, subtitles and fact-checks, and then negotiate access. My part was the connector, built on the open-source Eclipse Dataspace Components (EDC).

MY ROLE
  • Owned the connector side: the component each organisation runs to publish its data catalogue, prove who it is and negotiate usage contracts before any data moves.
  • Compared the two main open-source connectors (Eclipse EDC and FIWARE) and documented the trade-offs for the team.
  • Assembled our connector from EDC's Java modules with Gradle, containerised it with Docker and deployed it to Linux VMs behind Nginx.
  • Ran Eclipse's reference dataspace on Kubernetes (KinD, deployed with Terraform) and built a demo of catalogue requests and contract negotiation.
  • Wrote the team's technical documentation on connectors, the EDC control plane and the reference setup.
OUTCOMES

Working proofs of concept and documentation that fed into the project's research on searching across dataspaces.

TECH

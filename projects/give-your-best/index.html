Give Your Best

Company Website
OVERVIEW

Give Your Best is a UK charity whose webshop lets refugees choose and order donated clothes for free. I joined as a contractor to extend the platform during a period of growth, and have kept working on it since, in paid projects and as a volunteer. The platform has handled over 60,000 donated items and supported more than 5,500 people.

GYB
MY ROLE
  • Bulk donations: a new data model and API so donors can list one item in many sizes and quantities, with ordering rules and stock limits.
  • Reporting: the original report ran inside the web request and took the production server down, so I rebuilt it as a background job that generates an Excel workbook and emails it to staff, along with database indexes and some query optimisation.
  • Automated reports: recurring CSV reports emailed to staff, such as a weekly list of London shoppers that staff used to ask developers to pull from the database.
  • Donor privacy and safety: items from donors who aren't yet trusted go via the charity's office to be checked first, and donor emails no longer appear in API responses.
EXAMPLE FEATURE

The shop had grown organically and only really supported womenswear: navigation, category rules and legacy data behaviour were hard-wired. Adding Menswear meant either duplicating everything or restructuring.

I restructured it around one configuration model shared across the app, covering routing, navigation, breadcrumbs and API filtering, with one shared section component for the Womenswear, Menswear and Children's pages.

Menswear launched without duplicated code, the navigation became consistent across sections, and older items without the new data still show up.
